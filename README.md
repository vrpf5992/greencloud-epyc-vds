## 绿云 EPYC VDS 和普通 VPS 差在哪

核心区别只有一条：CPU 是 100% 独占的物理核心。官方对这条产品线的原话是 "You have 100% dedicated resources: 100% Physical CPU cores, RAM and RAID-10 NVMe 4.0"——也就是说你买到的每个核心都是真实物理核，不和别人共享，不存在 CPU steal。普通 KVM VPS 的核心是超分共享的，负载一高就要排队，这也是同样核心数下 VDS 跑分明显更稳的原因。

虚拟化是 KVM，面板用 VirtFusion，支持自助重装系统、自定义 ISO、快照，附 1 个免费备份/快照槽（只覆盖主盘）。定位是无托管：绿云只管硬件和网络在线率，系统里的问题自己解决。付款后开通通常在 15 分钟内，偶尔会拖到 2 小时。

一句话判断要不要买这条线：你的应用吃 CPU 单核性能、对邻居干扰敏感，EPYC VDS 值这个差价；只是挂个轻量站、跑个脚本，绿云自家的 Budget KVM 系列（$25/年起）便宜得多，没必要上 VDS。

## 藏在条款里的限制

这几条写在服务条款和套餐细则里，下单前值得过一遍：

- **端口是公平共享的**：持续 6 小时超过 100 Mbps，或频繁打满端口突发，是不被允许的。10Gbps 的标称带宽适合突发和大文件传输，别当独享 10G 恒定管道用。
- **禁止用途**：游戏服务器（Counter-Strike、Half-Life、Battlefield 1942 等）、TOR 节点、流媒体/直播推流，以及持续 10 分钟以上占满 100%+ 系统资源。
- **备份只有 1 个免费槽**：每日定时备份要买付费 add-on，重要数据别指望默认配置兜底。
- **DDoS 防护很薄**：实测机型标注 L3/L4 5Gbps，测评原话是“相当于没有”。容易挨打的应用要另想办法。

退款规则相对友好但有边界：**新客户、首个 VPS 套餐、账户注册后 7 天内**可退款，加密货币付款不可退。促销折扣款历史上退款执行得更严格（社区反馈负面评价多集中在账单纠纷而非服务器性能），所以想试水就用原价月付开 EPYCVDS-1，7 天内跑一轮 benchmark 不满意就退。👉 [月付 $10 开通 EPYCVDS-1，7 天内可退](https://greencloudvps.com/billing/aff.php?aff=6679)

**支持 Windows 吗？** 不支持。EPYC VDS 只提供 Linux，需要 Windows 得看绿云的 Windows VPS 产品线（$10/月起）。

**能用支付宝付款吗？** 可以。支持 PayPal、信用卡、银联、支付宝、加密货币以及美/英/欧银行转账。注意走加密货币就失去了 7 天退款资格。
